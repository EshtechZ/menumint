# MenuMint MVP

Static landing page and live sample menu for the Restaurant Direct-Order Starter experiment.

## Files

- `index.html` — offer and lead form
- `demo/index.html` — interactive customer-facing menu example
- `styles.css`, `app.js`, and `demo/` assets — page behaviour and styling
- `acquisition-funnel.md` — initial validation protocol
- `experiment-log.md` — running metrics and decisions

## Before publishing

1. The enquiry form is connected to the owner-controlled inbox. Its first submission will send an activation link to the inbox; approve that link before public launch.
2. Publish the folder through a free static host, ideally GitHub Pages.
3. Add the host's free analytics script or enable its built-in web analytics.
4. Test one form submission and one demo order click.

The visible business name is a temporary validation name; no trademark or registration claim is made.
